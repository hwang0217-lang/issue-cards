# Impeccable 소셜 디자인

사용자 2026-11-05 지시를 기본 적용한다. 공식 https://github.com/pbakaus/impeccable 의 설치된 SKILL.md와 필요한 new-work, craft-floor, typeset, adapt 지침을 읽는다. 공식 엔진은 frontend용이므로 카드 이미지에 실행했다고 꾸미지 않는다. hierarchy/type/spacing/color/mobile review를 매체에 맞게 적용한다.

- 두 계정의 최근9편 표지·가능한 본문과 승인된 정상 Canva 작업물을 확인한다. 주제별 사진 역할·정보구조·페이지 전개를 새로 설계한다. 동일 템플릿의 사진·글 교체나 고정종 순환은 금지한다.
- 모든 카드/장면에 내용과 직접 관계있는 실제 촬영 사진을 넣는다. 실제 사진을 확보하지 못하면 AI 사진·장식 사진으로 대체하지 않는다. 원본 페이지·촬영자·허용 라이선스·확인일·이미지 SHA256·해당 장과의 관계를 기록한다. 뉴스 사진은 실제 사건 사진과 맥락용 스톡을 구분하고 권리 미확인 기사 사진은 가져오지 않는다. 다른 집 사진을 동일 집 전후로 표현하지 않는다.
- Canva 최종 디자인을 사용한다. 실제 사진과 별도 벡터 텍스트를 계획해 공식 design-import로 Canva에 가져오고 최종 export를 검수하는 방식도 사용 가능하다. 가져오기 전 로컬 렌더를 Canva 최종 결과라고 하지 않는다. 기존 승인대기 트랜잭션은 건드리지 않는다.
- 사진의 주요 대상·원본 프레임을 보존한다. 기본 contain이며 크롭은 실제 대상이 안 잘리는지 검수한 경우만 허용한다. 텍스트는 사진의 복잡한 부분에 겹치지 않게 분리한다. 본문 위 선 금지, 최소24px 분리.
- 1080px 기준 본문44px 이상·확실한 제목 위계·본문 대비4.5:1을 기준으로 한다. 4:5 카드의 본문은 가장자리64px 안쪽, 9:16 영상의 핵심 정보는 상단210px/하단340px 및 좌우64px를 피한다. 이는 편집 기준이며 모든 플랫폼 UI를 실제기기로 검증했다는 뜻이 아니다.
- 모든 Canva 최종 페이지 원본100%와390px 축소본을 실제로 본다. 한글 누락/오타/줄끝·글자·사진 잘림/본문 겹침/대비/사진-내용 관계/반복/안전영역을 페이지별로 기록한다. 원고/좌표만 확인하고 통과시키지 않는다. 모바일 이미지 검수와 실제 휴대폰 실기기 검수를 구분한다.
- 영상은 최종 재생에서 읽기시간·전환·음악·플랫폼 안전영역을 별도 확인한다. 20초에 강제로 맞춰 글을 빨리 지우지 않는다. 전체 영상 확인 없이 표지만으로 승인하지 않는다.
- 서버는 실제 최종 원본+390px 이미지로 모델 QA를 수행하고, 사람이 한 직접 검수와 구분한다. 구체적 페이지 관찰·사진 출처·최종해시를 남긴다. 이미지/영상 생성·API 성공은 디자인 합격이 아니다.
- 미리보기 요청은 미리보기까지만 수행한다. 기존 하루1편·중복차단·사회이슈 게시보류·추가구매 금지를 유지한다. source는 중앙 workspace.py save 검사 후 배포한다.
